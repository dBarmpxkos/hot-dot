Hot-Dot: Thermal 8-Dot Braille Interface

Project by Dr. Dimitris Barmpakos [cite: 2]

Principle of Operation

A finger-worn peripheral using 0201 SMT thermistors in self-heating mode to provide tactile feedback.

Technical Specifications

Component Specification
Actuators 2x4 Array 0201 Thermistors
Pitch 2.5mm Standard Braille
Link USB CDC (Serial) + Optical Anchor
